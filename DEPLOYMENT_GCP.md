# Deployment Guide: GeoMine on Google Cloud Platform (Cloud Run)

This guide walks you through deploying the **GeoMine** application (FastAPI backend + Next.js frontend) to **Google Cloud Platform (GCP)** using **Google Cloud Run**.

---

## Prerequisites

1. **GCP Account**: An active Google Cloud account with billing enabled.
2. **Google Cloud SDK (`gcloud` CLI)**: Installed on your local machine. ([Download here](https://cloud.google.com/sdk/docs/install))
3. **Docker**: Installed and running locally.
4. **Git**: Repository setup locally.

---

## Architecture Overview

- **Backend**: FastAPI app packaged into a Docker container, deployed on Cloud Run (`geomine-backend`).
- **Frontend**: Next.js app packaged into a multi-stage Docker container (standalone mode), deployed on Cloud Run (`geomine-frontend`).
- **Artifact Registry**: Storage for both Docker container images on GCP.

---

## Step 1: Initial GCP Setup

Open your terminal / PowerShell and run:

```bash
# 1. Authenticate with Google Cloud
gcloud auth login

# 2. Create a new GCP Project (or select an existing one)
# Replace `geomine-prod-app` with your desired Project ID
gcloud projects create geomine-prod-app --name="GeoMine"
gcloud config set project geomine-prod-app

# 3. Enable required GCP API services
gcloud services enable run.googleapis.com artifactregistry.googleapis.com cloudbuild.googleapis.com

# 4. Create an Artifact Registry Docker Repository
gcloud artifacts repositories create geomine-repo \
    --repository-format=docker \
    --location=us-central1 \
    --description="Docker repository for GeoMine app"
```

---

## Step 2: Deploy Backend (`geomine-backend`)

### Option A: Direct Build & Deploy via Cloud Build (Recommended - No local Docker required)

```bash
cd backend

# Build image on GCP Cloud Build and push to Artifact Registry
gcloud builds submit --tag us-central1-docker.pkg.dev/geomine-prod-app/geomine-repo/backend:latest .

# Deploy to Cloud Run
gcloud run deploy geomine-backend \
    --image=us-central1-docker.pkg.dev/geomine-prod-app/geomine-repo/backend:latest \
    --platform=managed \
    --region=us-central1 \
    --allow-unauthenticated \
    --set-env-vars="GEMINI_API_KEY=YOUR_GEMINI_API_KEY_HERE"
```

> 📌 **Note down the Backend URL** generated by Cloud Run (e.g., `https://geomine-backend-xyz-uc.a.run.app`).

---

## Step 3: Deploy Frontend (`geomine-frontend`)

Now navigate to the `frontend` folder and build/deploy using your **Backend URL** as `NEXT_PUBLIC_API_URL`.

```bash
cd ../frontend

# Replace with your actual deployed backend URL
export BACKEND_URL="https://geomine-backend-xyz-uc.a.run.app"

# Build image via Cloud Build passing the API URL build arg
gcloud builds submit \
    --tag us-central1-docker.pkg.dev/geomine-prod-app/geomine-repo/frontend:latest \
    --substitutions=_NEXT_PUBLIC_API_URL=$BACKEND_URL .

# Deploy Frontend to Cloud Run
gcloud run deploy geomine-frontend \
    --image=us-central1-docker.pkg.dev/geomine-prod-app/geomine-repo/frontend:latest \
    --platform=managed \
    --region=us-central1 \
    --allow-unauthenticated \
    --port=3000
```

---

## Step 4: Configure CORS on Backend

Update your backend Environment Variables or Cloud Run service config to accept requests from your new Frontend Cloud Run URL.

```bash
gcloud run services update geomine-backend \
    --region=us-central1 \
    --update-env-vars="FRONTEND_URL=https://geomine-frontend-xyz-uc.a.run.app"
```

## Verification & Summary

- **Frontend App**: Open `https://geomine-frontend-xyz-uc.a.run.app` in your browser.
